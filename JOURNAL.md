## Comment lire les sources

- **Conversation** : demande ou décision datée retrouvée ; elle n’atteste pas à elle seule d’une livraison ni de l’usage final d’un résultat.
- **Rapport** : travail et vérifications décrits au moment de sa rédaction ; les paramètres peuvent avoir changé depuis.
- **Sauvegarde** : nom de dossier indiquant une intervention probable ; ni date de création initiale du projet ni preuve d’une semaine complète de travail.
- **Git** : état versionné ; ne date pas automatiquement la création de tous les fichiers contenus dans le commit.
- Les semaines sans trace exploitable restent ouvertes, avec un marqueur, plutôt qu’un récit inventé.
